# 프론트엔드 테스트 목록

> 검증 항목과 결과를 모아 둔 문서입니다. 전체 검증 계획은 [../docs/07-verification.md](../docs/07-verification.md) 를 참고하세요.
>
> **기능을 추가하면 이 문서도 함께 갱신합니다.** 자동 테스트는 파일별 건수를, 수동 테스트는 항목과 결과를 추가합니다.

테스트는 두 축으로 나눕니다.

| 축 | 도구 | 확인하는 것 |
|----|------|-------------|
| **자동** | Vitest + MSW + happy-dom | 로직·상태·호출 횟수. 눈으로 볼 수 없는 것 |
| **수동** | 실제 브라우저 + 브라우저 MSW | 렌더 결과·포커스 이동·깜빡임·저장소·탭 간 동작 |

자동 테스트가 통과해도 브라우저에서 처음 드러나는 문제가 있습니다. 반대로 single-flight 처럼 화면으로는 확인할 수 없는 것은 자동 테스트로만 고정됩니다. 둘 다 필요합니다.

## 2. 수동 브라우저 테스트

### 준비

```bash
cd frontend
# .env.development 에 VITE_ENABLE_MOCK=true
npm run dev
```

- 접속 후 Console 에 `[MSW] Mocking enabled.` 가 보여야 합니다
- **같은 주소의 다른 탭은 모두 닫습니다.** `localStorage` 를 공유하므로 다른 탭이 토큰을 지워 테스트가 깨집니다 (아래 발견 ② 참고)
- 초기화: Application → Local Storage → `mock:db` 삭제

## 3. 실제 백엔드 통합 테스트

MSW 가 아닌 **실제 백엔드**(PR #25 인증 API)에 붙여 확인한 결과입니다. 모킹이 명세를 잘못 흉내 내면 모킹으로는 통과하고 실서버에서 깨지므로, 모킹 테스트와 별도로 진행합니다.

### 준비

```bash
# 백엔드 — backend/.env 에 JWT_SECRET_KEY · ADMIN_* · CORS_ORIGINS=http://localhost:5175 설정
#          재발급 확인용으로 JWT_EXPIRE_MINUTES=1
cd backend && uvicorn app.main:app --port 8000

# 프론트 — 셸 환경변수가 .env 보다 우선하므로 .env 를 고치지 않고 모킹을 끌 수 있다
cd frontend && VITE_ENABLE_MOCK=false npx vite --mode development --port 5175 --strictPort
```

## 5. 테스트 중 발견한 주의점

**① Chrome 비밀번호 관리자가 입력에 끼어듭니다.** 저장된 계정이 자동완성 미리보기로 채워지면 화면에는 값이 보이지만 `input.value` 는 비어 있습니다. 테스트 전 해당 사이트의 저장된 비밀번호를 지우거나 자동완성을 꺼 두면 혼동이 줄어듭니다.

**② 같은 주소의 다른 탭이 테스트를 깨뜨립니다.** `localStorage` 는 출처 단위로 공유되므로, 다른 탭의 앱이 `/api/auth/me` 에 실패하면 `clearTokens()` 를 호출해 **이쪽 탭의 로그인까지 풀립니다.** 테스트 전에 다른 탭을 모두 닫습니다.
이 과정에서 **일시적 오류 한 번에 모든 탭이 로그아웃되는 결함**을 찾아 #34 에서 고쳤습니다. 지금은 다른 탭이 실패해도 토큰을 지우지 않지만, 로그아웃처럼 의도적으로 지우면 여전히 모든 탭에 반영되므로 테스트 전 다른 탭은 닫습니다.

**③ 개발 서버 포트를 확인합니다.** 5173 이 다른 프로젝트에 점유되어 있으면 Vite 가 조용히 5174 로 옮겨 뜹니다. 두 앱의 제목이 같으면 어느 쪽을 보고 있는지 구분하기 어렵습니다. Console 의 `[MSW] Mocking enabled.` 유무로 확인합니다.

**④ 오래 열어 둔 탭에서 MSW 가 요청을 가로채지 못할 수 있습니다.** 모든 요청이 "서버에 연결할 수 없습니다"(`NETWORK_ERROR`)로 끝나면, 서비스 워커가 페이지와의 연결을 잃은 것입니다. 앱 결함이 아니며 **새로고침하면** 돌아옵니다 (2026-09-28 확인).

**⑤ 포매터를 기본 설정으로 돌리지 않습니다.** 프로젝트에 prettier 설정이 없어 `npx prettier --write` 를 그대로 쓰면 큰따옴표·세미콜론으로 바뀝니다. 2026-09-28 관리자 작업 중 기존 파일 30여 개가 바뀐 것을 커밋 전에 발견해 되돌렸습니다.
